# 🧠 AI Handwritten Digit Recognizer

A professional AI-powered handwritten digit recognition web application built using TensorFlow, OpenCV, and Streamlit.

---

## 🚀 Features

- ✍️ Handwritten digit recognition
- 🔢 Multi-digit sequence detection
- 🧠 CNN deep learning model
- 📊 Confidence score visualization
- 🎨 Modern glassmorphism UI
- ⚡ Real-time preprocessing
- 🖼️ OpenCV contour segmentation
- 💾 Incorrect sample saving

---

## 🛠️ Tech Stack

- Python
- TensorFlow / Keras
- OpenCV
- Streamlit
- NumPy
- Matplotlib

---

## 🧠 Model Architecture

The project uses a Convolutional Neural Network (CNN) trained on the MNIST dataset.

### CNN Pipeline

Input Image → Conv2D → MaxPooling → Conv2D → Flatten → Dense → Softmax

---

## 📂 Dataset

- MNIST Handwritten Digits Dataset
- 60,000 training images
- 10,000 testing images
